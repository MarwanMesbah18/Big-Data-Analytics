## Tasks

Each task is in its own folder, written in Python 3 (standard library only) and simulates MapReduce: map -> shuffle -> reduce.

| Folder | Task | Run |
|---|---|---|
| `word-count/` | Count each word | `python3 word-count/word_count.py` |
| `top-k-words/` | K most frequent words | `python3 top-k-words/top_k.py 10` |
| `inverted-index/` | Word -> files containing it | `python3 inverted-index/inverted_index.py` |

## Optional GUI

`python3 gui.py` opens a small window: choose a task, press **Run**, and the output appears in the box (for Top-K, type K first).
